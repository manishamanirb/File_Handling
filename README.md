Contact Management System Using Python

Project Description:

This project is a simple Contact Management System developed using Python as part of the CodeOrbit Tech Python Programming Internship.

It allows users to add, view, and search for contact details stored in a CSV file.

Features:

- Add new contacts
- View saved contacts
- Search contacts by name
- Store contact information in a CSV file
- Handle file-related errors

Technologies Used:

- Python 3
- CSV module
- File handling
- Visual Studio Code

How to Run:

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run "File_Handling.py" (or the actual Python filename in your repository).
5. Follow the menu options to add, view, or search contacts.

Concepts Used:

- Functions
- Loops and conditional statements
- CSV file operations
- Exception handling
- User input and output
